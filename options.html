Configuración de la extensión

Elegí cómo se conectará este perfil de Chrome a las plataformas.

Solo se guarda en el almacenamiento local de Chrome un UUID aleatorio para distinguir este perfil y seleccionar sus credenciales protegidas con DPAPI. La configuración, las sesiones y los movimientos se guardan en PostgreSQL.

Se usa para buscar usuarios en Ganamos. Si usás el puente, configurá el ID en el perfil Principal. Valor predeterminado: 38175478.

Usá letras diferentes. Configurá los mismos sufijos en todos los perfiles emparejados.

El perfil que ejecuta el alta usa esta contraseña para Ganamos y MultiPanel, también para solicitudes de perfiles secundarios.

Respaldo de este perfil Chrome

Exporta toda la información de este perfil, incluidos movimientos asociados a contactos, contadores, configuraciones y secretos. El archivo se cifra con una frase de contraseña. Los demás perfiles de Chrome no se incluyen.

La etiqueta queda visible en el nombre del archivo; no incluyas contraseñas ni datos personales.

Usá al menos 16 caracteres y guardá la frase por separado. Si la perdés, no se podrá recuperar el contenido del archivo. Se admiten payloads de hasta 24 MiB, archivos finales de hasta 32 MiB y 100 000 claves.

Importar respaldo y conectar este perfil a PostgreSQL

La extensión se conecta a la API HTTPS de la PC que aloja PostgreSQL; todos los perfiles y computadoras usan esa misma dirección privada de la LAN. Chrome debe confiar en el certificado TLS. Nunca abras el puerto SQL: solo la API debe ser accesible desde la red.

La vista previa requiere cargar primero los datos al staging cifrado temporal. Esto no cambia los datos funcionales; si no vas a confirmar, usá “Descartar” para eliminar ese staging.

Instalá primero el host nativo de Windows de esta extensión. Guarda las credenciales por perfil Chrome cifradas con DPAPI; los datos funcionales se leen y escriben en PostgreSQL.

El código lo genera el administrador para este perfil. Se usa una vez y no se guarda; La credencial revocable emitida por el servidor se almacena cifrada con DPAPI en Windows, separada por perfil Chrome.
